# 1.9.45

Swofty Launcher for F1 25 1.9.45 stops two warnings that appeared when nothing was wrong, and lifts the limit on installed tracks.

## Warnings

- "Careers that need addons" appears only when an addon that is off owns the career's own team, car or driver. Before, it also appeared for every track that had been driven in any mode, and for addons that were only on when the career was saved.
- Turning an addon off asks about your saves under the same rule.
- A career that no longer exists raises no warning.
- The warning no longer says the game won't start.
- "Mods did not load" no longer appears when the mod loader is running and waiting for the game window.

## Tracks

- More than 255 tracks can be installed. The game reads 255 at once; when every place is taken, a new track takes the place of a track that is off.
- On an added track, UDP telemetry reports track id -1 and sends a Swofty Track packet (id 200) after each Session packet, which names the track. Set `SWOFTY_UDP_TRACK_PACKET=0` to leave the extra packet out.

## Careers

- With many added engine suppliers, a team's R&D trees keep the team's own supplier and leave out those that don't fit in the game's 384 upgrade slots. Going over that limit crashed Team HQ. Set `SWOFTY_RND_SUPPLIER_GUARD=0` to turn this off.

## For addon creators

- `content.package` 1.4 adds `rules.tyre_warmers`, which sets tyre warmers per box.
- The `virtual-list` op takes `"host": "career"` for career lists.
- An addon's added-row ids include the stat ids of its tracks.

The R&D, tyre warmer, career list and track changes were contributed by vogtmarcel07-cloud.
